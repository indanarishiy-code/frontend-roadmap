# Frontend Developer Learning Roadmap

Self-study + practice repo working through 27 frontend topics, tailored
toward frontend developer roles in **Germany, Netherlands, Malaysia,
and UAE**.

Each topic is a flat folder at the root of this repo — the tiers below
are a study *order*, not a folder structure. Personal planning notes
(why this order, tier reasoning) live in my own roadmap doc, not
duplicated here.

## How to work through each topic

1. Within each topic's reference doc, use the Solid / Rusty / New to me
   system — don't re-read sections already marked Solid.
2. Do the suggested verification exercise at the end of each doc — it
   produces a real, demonstrable artifact (tested project, migrated
   component, working CI pipeline), not just passive review. Track
   completion in that topic's `README.md`.
3. Don't fully finish one topic before starting the next if momentum
   stalls — the order above is priority, not a rigid gate.

## `sandbox/`

Scratch space for breaking things freely — not held to the same
tidiness standard as the topic folders.

## Commit habit

Commit per exercise, not per session, so the history stays skimmable —
and doubles as a visible progress log across all 27 topics.
